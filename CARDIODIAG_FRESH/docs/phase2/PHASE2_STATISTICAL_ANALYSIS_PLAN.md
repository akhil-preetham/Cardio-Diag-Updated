# Phase 2 Statistical Analysis Plan

Report ROC-AUC, average precision, Brier score, log loss, calibration intercept/slope, sensitivity, specificity, PPV and balanced accuracy. Treat repeated-fold results as dependent. Use fold/repeat variability descriptively. Decision curves are exploratory because no clinical decision threshold was prespecified. Do not treat cross-validation standard deviations as independent-sample confidence intervals. Do not use outer-test results to select a stage or model.
