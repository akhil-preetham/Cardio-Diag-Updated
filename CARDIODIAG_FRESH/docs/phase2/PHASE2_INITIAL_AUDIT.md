# Phase 2 Initial Audit

The repository contains preserved V1-V4 experiments, V3 fully nested calibration, the comprehensive research package, exact Stage 6 split manifests, clinical feature audits and independent verification artifacts. The strict Z-Alizadeh primary analysis is reproducible. The earlier symptom and ECG apparent improvements come from exploratory feature groups whose timing and/or coding remain unverified. EF-TTE, Region RWMA and VHD are downstream or diagnostic-stage variables and are excluded from pre-test models. No compatible untouched external cohort is currently available. Historical directories are not modified by Phase 2.

The existing model evidence covers L2 logistic regression, SVM, random forest, Extra Trees and histogram gradient boosting. Elastic-net, Firth, generalized additive and Bayesian logistic models were not executed in this phase: no validated Firth/GAM/Bayesian implementation was present in the frozen environment, and installing new modeling dependencies would not resolve the primary clinical timing and external-validation blockers. This is an unresolved model-sensitivity limitation, not evidence that the omitted models would perform better.
