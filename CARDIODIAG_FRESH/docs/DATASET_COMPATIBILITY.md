# Dataset compatibility

The compatibility matrix is `data/metadata/feature_compatibility_matrix.csv`. Five States and Mendeley are baseline disease-presence datasets but have different schemas. Kaggle CVD is a separate 70,000-row disease-presence benchmark. UCI Cleveland and Statlog share heart-disease concepts but may overlap and require source-level overlap analysis. UCI Heart Failure is a separate mortality/follow-up task and must not be merged.
