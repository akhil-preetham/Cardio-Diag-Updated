# Request for Independent CAD Cohort

Subject: Request for de-identified cohort for external validation of an angiographic CAD prediction model

We request a de-identified cohort of adults undergoing coronary angiography for suspected CAD. Required fields are age, recorded sex, current smoking status, former smoking status, family history of CAD, a prespecified angiographic CAD outcome, timing of each predictor, timing of angiography, patient-local study key, missingness indicators and source/site identifiers coded without direct identifiers.

Please provide the data dictionary, outcome adjudication protocol, stenosis measurement method, source population and dates, inclusion/exclusion criteria, missing-data report, duplicate/patient-overlap assessment, license/data-use terms, ethics approval or exemption, and secure-transfer requirements. No direct identifiers should be transmitted. The analysis team will freeze the V3 model before external evaluation and will not refit on the untouched validation cohort.
