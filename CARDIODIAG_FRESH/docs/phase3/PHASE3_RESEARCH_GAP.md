# Phase 3 Research Gap

The unresolved gap is not another classifier score; it is a patient-level, timing-documented, independent angiographic CAD cohort containing the same five predictors. Public candidates either use different modalities, lack the predictors, require restricted access, have small sample sizes, or provide EHR codes rather than a verified angiographic endpoint. The next contribution should establish this cohort and transparently validate the frozen model before exploring updates.
