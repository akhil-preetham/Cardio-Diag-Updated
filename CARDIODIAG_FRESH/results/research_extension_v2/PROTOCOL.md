# Reliability follow-up v2: protocol frozen before experiment execution

Dated 14 November 2026. This is an additive, retrospectively motivated investigation on already examined public cohorts. No newly independent clinical validation or algorithmic priority is claimed. The established release, runners, predictions and report remain unchanged. All specified arms are retained, including worse results. This protocol is frozen with code and input hashes before executing the actual experiments.

## Questions and fixed analyses

1. **Semantic feature typing:** compare a fixed 38-field typed L2 pipeline with the historical equal-feature L2 control on the same 15 source outer partitions and original C grid [.1,1,10]. Continuous fields are Age/BP/PR and fourteen laboratories, Function Class ordinal0..3, numeric indicators binary0/1, remaining symptom/ECG/sex fields nominal. Median/scale only continuous/ordinal; mode and one-hot(drop if binary) for categories. All transforms fitted within training. The historical post-selection raw-score sigmoid/Youden rules are deliberately retained for matching; these controls are not independently calibrated.
2. **Calibration stability:** reuse all 45 frozen independent v1 calibration blocks and their unchanged outer raw probabilities. Fit intercept-only offset, logit-slope sigmoid with fixed C=1, and logit-slope sigmoid with C selected from[.1,1,10] by three-fold calibration-block negative log loss. Selection of C occurs only in calibration training, never outer tests. Contrast with existing weak raw-score sigmoid and identical raw ensemble. No base model refits are needed. Retain all maps, coefficients and inner scores. Primary loss Brier; AUC/log loss secondary. Means/ranges over overlapping repeats are descriptive.
3. **Missing-input robustness:** fit ordinary shared-core L2 and an optional training-augmentation estimator on source training folds only, C[.1,1,10] selected with clean inner AUC. The latter adds one independent20%MCAR-masked copy of training X, half weight per original/copy, imputation plus indicators for every field. Augmentation happens inside each estimator.fit, after every inner split, so copies never leak into validation. Same source folds/seeds as v1. Compare on exact v1 fixed MCAR masks0/10/25/50%, plus prespecified whole Age, Current Smoker and DM+HTN+Smoker block deletion. No additional refits for test scenarios. No MNAR robustness or artificial-independent-patient claim.
4. **Target adaptation, new analysis:** existing source predictions on AngioCAD are frozen. Three repeats of stratified five-fold target adaptation/evaluation. In each fold, fit maps only on other target folds: constant adaptation prevalence, intercept-only offset, logit sigmoid C1 and inner-CV sigmoid C[.1,1,10]. Evaluate original frozen raw and source-calibrated probabilities on identical held-out records. All377 cases predicted once/repeat. Record source case keys and fold roles. Target labels were already explored in earlier work: call this retrospective target-adaptation cross-validation, not untouched external validation. Principal target>50; excluded10boundary and upper-assignment sensitivities score the same predictions without relabelling calibration training. No threshold optimization;0.5 diagnostic only.
5. **Uncertainty:**1000 paired source-record bootstrap draws use one303-row sample across all three repeats, retaining correlation; these condition on saved fits and unverified source-row independence. Separately50 bootstrap-development L2 refits use sampled source IDs, StratifiedGroupKFold3 for C tuning (duplicate copies share a group), evaluate only out-of-bag IDs. Report this refitting/OOB sensitivity distribution, not a full30-family or patient-level confidence interval.
6. **Subgroups:** fixed sex groups and age<=60/>60/missing; report class counts, AUC/Brier and instability if either class<10. ZAS uses repeat1 for each model, target-adaptation uses repeat1. These describe subgroup performance, not fairness certification. No outcome-guided subgroup discovery or fairness optimization.

## Preservation and decision rule

All source/data/code/v1 checkpoint hashes must match before analysis. The default released model and prior scientific conclusions remain frozen. For clean-source non-regression, a candidate must have mean AUC >= its stated comparator and mean Brier <= it (tolerance1e-10); this is a descriptive gate, not a statistical superiority claim. Any failing candidate is not promoted; robustness or adaptation results are separately scoped. All choices above are retained, with no score-driven extra model/grid/search. If results are mixed, finish with an evidence-based trade-off report rather than changing the target or hiding failures.

Predictor timing, verified patient IDs, finer stenosis values, authoritative binary ascertainment, new compatible cohorts and institutional declarations cannot be created by code. Record their disposition as evidence-dependent unresolved items, with the current retrospective scope retained.
