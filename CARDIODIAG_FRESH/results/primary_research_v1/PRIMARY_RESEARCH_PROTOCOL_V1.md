# CARDIODIAG Primary Research Protocol v1

## Research question

Can models trained on routinely available, strictly pre-diagnostic variables distinguish
coronary artery disease (`Cath = Cad`) from normal catheterization (`Cath = Normal`) in
the Z-Alizadeh Sani cohort, while reporting discrimination, calibration, uncertainty, and
interpretable feature associations without diagnostic-procedure leakage?

This is an internal-validation study. It does not establish clinical utility, deployment
readiness, prospective prediction, or external validation.

## Population and target

The source is UCI dataset 412, Z-Alizadeh Sani: 303 records, 216 CAD cases and 87
normal cases. The binary target is `1` for `Cath = Cad` and `0` for `Cath = Normal`.
Rows with invalid or missing target values are excluded from the derived modeling table;
the raw source and validated derivative are not modified. No patient identifier is
available for additional grouping, and the duplicate audit found no exact or
predictor-only duplicate records in this dataset.

## Frozen predictor eligibility

The strict primary feature set is frozen before model fitting:

`Age`, `Sex`, `Current Smoker`, `EX-Smoker`, and `FH`.

These are the only features classified as unambiguously eligible in the clinical audit.
Variables requiring timing, unit, or clinical review are excluded from the primary
analysis until their prediction-time availability is documented. `Cath` is the target.
`EF-TTE`, `Region RWMA`, and `VHD` are excluded as downstream diagnostic variables.
`Exertional CP` is constant and is excluded as non-informative. The complete 56-column
eligibility table is saved as `FEATURE_ELIGIBILITY_FINAL.csv`.

An exploratory timing-sensitive feature set is not used to support the primary result.
Any future analysis using uncertain variables must be separately labeled and must not be
combined with the strict estimate.

## Preprocessing and validation

The primary experiment uses five repeats of shuffled, stratified five-fold outer
cross-validation. Each outer training partition uses a four-fold stratified inner CV for
hyperparameter selection, with a seed derived from the outer repeat and fold. Every
record is evaluated only in its outer test fold for that split. Split assignments are
saved with anonymized source row indices.

Numeric columns use median imputation and standardization; `Sex` uses most-frequent
imputation and one-hot encoding. Each transformer is fitted inside the model pipeline
on the relevant training data only. No target-derived preprocessing, resampling, or
threshold selection uses outer test labels.

## Models and imbalance handling

The compact model set is:

1. Logistic regression.
2. Support vector classifier.
3. Random forest.
4. HistGradientBoosting.
5. Extra Trees.

For models supporting it, unweighted and `class_weight="balanced"` variants are
compared. HistGradientBoosting is evaluated without class weighting because its
scikit-learn implementation does not expose a class-weight parameter. No SMOTE is used
in the primary experiment because the cohort is small and the protocol's primary
imbalance comparison is class weighting versus no weighting.

## Outcomes and hypotheses

The prespecified primary metric is ROC-AUC. Secondary metrics are PR-AUC, balanced
accuracy, sensitivity, specificity, precision, F1, Brier score, log loss, calibration
intercept, calibration slope, and ten-bin expected calibration error. Threshold-dependent
metrics use a fixed probability threshold of 0.5; no optimized threshold is used.

The primary hypothesis is that at least one compact model will provide useful
discrimination above chance without downstream variables. Secondary hypotheses concern
whether class weighting changes PR-AUC or operating-point metrics and whether sigmoid
calibration improves probability quality. Evidence is descriptive and uncertainty-aware;
the small single-cohort sample limits confirmatory claims.

## Calibration and uncertainty

Uncalibrated probabilities are generated by the model fitted through inner selection.
Sigmoid calibration is fitted by `CalibratedClassifierCV` using only the outer training
partition and its inner folds, then applied once to the outer test partition. Calibration
is never fit on outer test labels.

Uncertainty is reported as variation across outer folds/repeats and deterministic
observation-level bootstrap intervals on aggregated repeated-CV predictions. These
bootstrap intervals quantify resampling uncertainty for this cohort and are not
confidence intervals for an independently sampled population.

## Explainability and statistical comparisons

Permutation importance is computed for each outer test partition using the fitted
uncalibrated pipeline and saved per feature, model, repeat, and fold. It is an
associational predictive explanation, not a causal effect. Logistic coefficients and
feature stability summaries are included where available.

Model comparisons use paired observation-level bootstrap differences on aggregated
outer predictions. Ordinary independent-samples tests on correlated CV folds are not
used. P-values are not reported as confirmatory evidence; the analysis reports effect
estimates and percentile intervals with the dependence limitation stated explicitly.

## Generalization boundaries

The Cleveland and Statlog files are confirmed record-level matches and are not
independent validation cohorts. Five States, Mendeley, and Kaggle cardiovascular
disease have incompatible or unresolved target/provenance relationships and are not
used for external validation. NHANES remains a weighted cross-sectional descriptive
track. PTB-XL and PTB Diagnostic remain separate ECG tracks.

## Reproducibility and stopping rules

All seeds, feature names, model configurations, split assignments, predictions,
hyperparameters, warnings, environment versions, input hashes, and output hashes are
recorded under `results/primary_research_v1/`. Historical results are never overwritten.
If a model or analysis fails, the failure is recorded rather than silently omitted.
