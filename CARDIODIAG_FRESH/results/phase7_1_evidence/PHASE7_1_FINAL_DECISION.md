# Phase 7.1 final decision

## Classification

**READY WITH SPECIFIED EVIDENCE LIMITATIONS** for later manuscript reconstruction as a retrospective discrimination evidence audit.

The selection-aware Phase 6 ZAS result is internally coherent and independently reconciled against saved outer predictions. The selection-aware procedure exceeded its V3 comparator in all three repeated source-row split estimates (AUC differences +0.1764, +0.1579 and +0.1877; mean +0.1740). This supports a within-dataset retrospective discrimination comparison under the frozen selection procedure. Phase 5’s 0.928 result remains exploratory and post hoc.

The evidence does **not** support a prediagnostic prediction paper because feature acquisition timing is unverified. Patient-level independence is not established. Phase 6 calibration has selection-dependent crossfit scores and training-size mismatch, although the outer discrimination evaluation remains verified. No external validation or clinical utility is established. UCI remains a separate four-centre staged track, not a ZAS validator.

The current manuscript is not yet ready as a final submission document: it predates Phase 6/6.1, and author declarations, ethics determination and final LaTeX visual QA remain outstanding. This package is ready as the evidence basis for a controlled manuscript reconstruction; it does not modify or rewrite the manuscript.

## Evidence status

- **Supported:** Phase 5 metric reconstruction as post-hoc; Phase 6 outer discrimination and paired arithmetic; Phase 6.1 prediction/metric reconciliation; UCI pooled staged metrics and paired record-level increments.
- **Limited:** calibration interpretation, three-repeat split variation, feature-level interpretation, centre-specific UCI stability and record-bootstrap scope.
- **Unresolved:** predictor timing, unique patient identity, independent compatible ZAS validation, transportability, clinical utility, and required author/governance declarations.

## Reproduction and audit commands

From the project root in PowerShell, use the existing project environment. These commands only read prior artifacts and run focused audits/tests; they do not rerun model selection or refit the benchmark:

```powershell
$env:PYTHONPATH = 'src;.'
.\.venv\Scripts\python.exe -m runner.phase6_1_audit.audit
.\.venv\Scripts\python.exe -m pytest tests\test_phase6_1_audit.py -q
.\.venv\Scripts\python.exe -m ruff check runner\phase6_1_audit tests\test_phase6_1_audit.py
```

Phase 4.3 audit reproduction (which recomputes saved metrics and figures, not model training) is documented in `results/phase4_validation_audit/PHASE4_3_FINAL_REPORT.md`; it uses `.venv-repro`. Phase 6 benchmark reproduction is intentionally not run here. Phase 7.1 evidence files are a consolidation of saved artifacts and were not generated by model fitting.
