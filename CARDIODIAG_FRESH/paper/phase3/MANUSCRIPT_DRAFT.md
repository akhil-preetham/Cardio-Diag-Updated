# CARDIODIAG Phase 3 Manuscript Draft

Phase 3 prepared CARDIODIAG for external validation but did not claim that validation occurred. Public dataset discovery identified several related resources, none of which currently satisfies all five predictor, timing, endpoint and independence requirements. A frozen external-validation protocol and institutional cohort acquisition package were created. The next study must obtain a timing-documented, independent angiographic CAD cohort and evaluate the frozen V3 model before any recalibration or model updating.
